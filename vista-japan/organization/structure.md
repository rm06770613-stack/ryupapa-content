# VISTA JAPAN 組織設計

## 法人概要

| 項目 | 内容 |
|------|------|
| 法人名 | 一般社団法人 VISTA JAPAN |
| 法人形態 | 一般社団法人（非営利型） |
| 設立目標 | 2027年1月 |
| 所在地 | 石川県加賀市（予定） |
| 代表理事 | 見付竜一 |

### 非営利型を選ぶ理由
- 補助金・助成金・行政との連携がしやすい
- 公益性の高い地域スポーツ育成事業に適している
- 将来の議員活動・地域政策との整合性

> スクール事業・チーム運営は収益事業として課税対象になるが、非営利型であることで地域からの信頼と助成金獲得で優位に立てる。

## 役員報酬の設計

- 代表理事（見付竜一）の報酬は社員総会での決議が必要
- 目安：営業利益の40%を役員報酬として取得
- 残り60%を法人内部留保として翌年の投資資金に充当

**運用ルール**
```
営業利益 × 40% → 代表理事報酬
営業利益 × 60% → 法人内部留保
```

内部留保の主な使途：
- 翌年の事業立ち上げ資金
- 設備投資（ビジョントレーニング機器等）
- 選挙準備・地域活動資金
